# Pixel Art LEGO

Générateur de pixel art LEGO à partir d'une image : recadrage, réglages couleur, conversion sur la palette LEGO et liste des plaques 1×1 à utiliser (avec codes couleur BrickLink).

**Démo : https://jswale.github.io/pixel/**

## Fonctionnalités

- Recadrage interactif et résolution réglable (plaques 16×16, 32×32, 48×48 ou taille libre)
- Réglages teinte / saturation / valeur / luminosité / contraste
- Rendu en picots LEGO en relief ou en ronds plats
- Tableau des pièces et export PNG

## Lancer en local

Page statique sans dépendance : ouvrir `index.html`, ou servir le dossier :

```bash
python -m http.server 8934
```
